## 🧩 V4.0 组件规范

### 1. COIN 导轨滑块（重设计）

```
┌────────────────────────────────────────┐
│          ┌──────────┐                  │
│          │  COIN    │  ← 金色标签      │
│          └──────────┘                  │
│  ════════●════════════════  ← 导轨     │
│          ↑ 金色圆形拖拽柄 (36×36)      │
└────────────────────────────────────────┘
```

**规格：**
- 导轨宽度：屏幕宽度 - 40px padding
- 导轨高度：8px，圆角胶囊，深色背景+内阴影
- 拖拽柄：36×36 金色圆形，金色发光阴影
- COIN标签：金色边框，黑色背景，圆角矩形
- 金币投下位置：跟随滑块X坐标

### 2. 老虎机格挡柱

```
│ K │ | │ 9 │ | │ J │ | │ K │ | │ ♦ │
        ↑ 格挡柱（4根，在5列之间）
```

**规格：**
- 格挡柱宽度：3px
- 格挡柱颜色：紫色 (#8B2FC9) + 紫色发光
- 格挡柱高度：与老虎机网格等高
- 物理行为：金币X坐标接近格挡时，施加反向水平速度

### 3. 水果行格挡

```
│🍎│ ▲ │🍊│ ▲ │🍇│ ▲ │⭐│ ▲ │🔔│ ▲ │🍉│ ▲ │🍋│
       ↑ 剑/针形格挡（6个，在7个图标之间）
```

**规格：**
- 格挡：三角形或竖条，铜色金属感
- 高度：30px，突出水果行范围
- 物理行为：同格挡柱，改变金币水平速度

### 4. BONUS 宽幅滑块（重设计）

```
┌─────────────────────────────────────────┐
│  ♠A  ♠A    [BONUS]●───────────  💰💰  │
└─────────────────────────────────────────┘
```

**规格：**
- 宽度：与水果行等宽（屏幕宽 - 40px）
- 高度：50px
- 背景：深棕色卡牌区域，左侧有纸牌装饰
- BONUS标签：金色圆角矩形，字体加粗
- 轨道：从BONUS标签延伸至右侧
- 拖拽柄：金色圆形，橙色边框，20×20

### 5. 新手引导箭头

```
         ↓↓↓  ← 金色双箭头，向下指向投币按钮
         ↓↓↓  ← 闪烁动画（1秒循环，淡入淡出+位移）
       [投币按钮]
```

**行为：**
- 初始状态：显示（showTutorialArrow = true）
- 触发消失：用户第一次点击投币按钮
- 动画：上下浮动 + 透明度 0.2~1.0 循环
- 不受5秒自动消失限制，必须等用户点击

### 6. 推币区（像素级还原）

```
    ┌─╗                         ╔─┐
    │喷│                         │喷│   ← 左右喷管
    │管│                         │管│
    └─║─────┐           ┌─────║─┘
            │  ╲       ╱  │           ← 两块向下倾斜绿板
            └───╲     ╱───┘
                 ╲   ╱
                  ╲ ╱
           ┌─────────────┐            ← 黑色推币滑块（左右移动）
   ════════════════════════════       ← 金色底板
   💰💰💰💰💰💰💰💰💰💰💰💰       ← 金币堆（物理模拟）
```

**规格：**
- 喷管：左右各一，黑色圆管形，定期喷出金币动画
- 绿板：SCNNode绿色斜面，friction=0.1（滑溜），让金币滚落至中间
- 推币滑块：SCNBox，黑色，kinematic物体，左右来回运动
- 金币堆：80枚预热金币，随机散布

## 📐 V4.0 物理系统规范

### 2D物理坐标系

```
屏幕坐标原点：屏幕中心
Y轴：向下为正
X轴：向右为正

区域划分（相对于屏幕中心）：
- COIN滑块：Y = -200（在中线以上）
- 老虎机格挡区：Y = -100 ~ +50
- 水果行格挡区：Y = +80 ~ +140
- BONUS滑块：Y = +140 ~ +180
- 进入3D区：Y > +200
```

### 碰撞检测参数

```swift
// 老虎机格挡（5列间4个格挡）
slotBaffleXPositions = [-144, -72, 0, 72, 144]  // 相对屏幕中心
slotBaffleYRange = (-100, +50)
baffleCollisionRadius = 8  // 金币X距格挡<8时触发

// 水果行格挡（7图标间6个格挡）
fruitBaffleXPositions = [-120, -80, -40, 0, 40, 80, 120]  // 近似位置
fruitBaffleYRange = (+80, +140)
```

### 金币物理参数

```swift
gravity = 800.0  // px/s²
initialVY = 0    // 从静止开始
initialVX = ±10  // 微小随机水平速度
bounceFactor = 0.6  // 碰撞反弹系数
friction = 0.95  // 水平速度衰减（每帧）
```

## 🎮 V4.0 玩家体验设计

### 核心乐趣循环

```
投币 → 金币下落（有物理趣味性）
    → 撞上老虎机格挡（改变轨迹，不可预测性）
    → 穿过水果行（点亮图标）→ 全部点亮 → 卡牌奖励
    → 穿过BONUS滑块（如果对准了）→ 老虎机旋转 → 灯光效果
    → 落入推币台（3D物理）→ 推出金币 → +1奖励
```

### 吸引玩家的设计要点

1. **不可预测性**：格挡碰撞使金币轨迹充满变数，类似真实物理机
2. **即时反馈**：每次碰撞有视觉效果，水果点亮有发光动画
3. **多重奖励层次**：水果全亮奖励 + BONUS旋转 + 推币掉落奖励
4. **滑块互动**：玩家主动调整COIN和BONUS位置，增加操控感
5. **新手友好**：箭头指引，降低首次进入的困惑感
