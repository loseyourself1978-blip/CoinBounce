## v9.8.0 (2026-10-26)

- **开局预铺金币**：每次启动在推币台上按六边形密排预铺一层金币，最前排贴近掉落线，最后一排贴着推板最远处。参数在 `GameConstants`（`prefillMaxRows`、`prefillEdgeGap`、`prefillBackGap`、`prefillRowLooseness`）。推板空转时不掉落；在 SE / 16e / 16·17 / Pro Max 尺寸下投 4～5 枚币就会推落第一枚。屏幕尺寸变化时，如果推币台还没落上新金币，会按新布局重新预铺。
- **推币台物理**：推板以金币边缘接触（原来以金币中心判断）；金币重叠按位置分离，迭代 `bedSolverPasses` 次，推力能沿着金币堆传到前排，不再只是叠到彼此上面。
- **推币台底图**：删除参考截图 `coin_pusher_ref`（含版权风险），改为代码绘制的简化推币台：后挡板、左右侧栏（带灯）、引导斜坡、绿色台面、推板、前沿掉落口，不画任何金币。同时删除了喷币管装饰。

- **界面细节**：前沿掉落口加高到超过一枚金币（`bedDropY` 上移），最前排金币不再挡住口子；投币按钮略下移，引导箭头和「金币不足」提示放在投币区内，不再被推币台盖住；战斗区格挡移到两侧人物之间、VS 下方，VS 和连击文字放在顶部，不再与 BOSS 文字重叠；修复树木装饰把战斗区撑宽、边框出屏的问题。
- **测试**：新增预铺测试（不越界、不重叠，空转掉落不超过 2 枚，投 5 枚至少推落 1 枚，掉落按 `bedDropReward` 计分，换布局后重新预铺），共 59 个用例全部通过。

## v10.0.0 (2026-10-27) — 阶段 1：布局与下落区

- **布局顺序**：顶栏 → COIN 投币口轨道（最顶端，带上下两排跑马灯）→ 老虎机 → 战斗区 → 水果灯排 → BONUS 轨道 → 推币台 → 投币按钮。金币从最顶端落下，依次经过各层。
- **下落区改用 SpriteKit 物理**（`UI/DropFieldScene.swift`）：
  - 真实重力、空气阻力、碰撞和金币之间的互相碰撞。
  - 老虎机 15 个符号格和 SPIN 按钮是碰撞体，金币在符号之间弹跳；水果灯之间有小钉。
  - 下落时金币绕竖轴翻转（正面和侧面贴图交替）。
  - 金币越过水果灯排时按所在列点亮水果；穿过 BONUS 牌中间时启动老虎机；越过下落区底部后交给推币台。

- **规则层**：`GameState` 去掉了手写的下落物理，改为接收下落区事件（`coinCrossedFruitRow`、`coinCrossedBonusLane`、`coinHitObstacle`、`coinReachedPusher`）。碰撞只播放音效和震动，不再计入连击（真实物理下碰撞太频繁）；水果命中仍计连击。
- **测试**：用布局和事件测试替换旧的下落物理测试（投币口在老虎机上方、符号格障碍在转轴内且金币能通过、水果列判定、BONUS 判定、交接到推币台），共 86 个用例全部通过。

## v11.0.0 (2026-11-01) — 推币台物理重建

- **根本原因**（用 `-autoplay` 每秒统计确认）：开局金币堆只铺在台面中线之前（z ≥ 0），推板推到最远只到 z = -1.3，永远碰不到金币堆，所以前沿从不掉币（fallen 始终 0）；金币只进不出，涨到上限 190 后，新落下的金币在 `addCoin` 里被直接丢弃（45 秒内 rejected 从 0 涨到 97）——这就是「金币落到推板上就消失、金币堆完全不变」。以前的验收只做几何检查和离屏渲染，离屏渲染器不跑物理，没能发现。
- **金币堆**：从台面前沿一直铺到推板推到最远时的前沿，推板每次推出都顶到金币堆；第一排像真机一样探出前沿约 45%。上限 190 → 400（只作保险，正常游玩达不到）。
- **完整物理链**：2D 金币沿视线交接为 3D 金币（屏幕位置、大小一致）→ 落在推板顶面或斜坡上 → 推板收回时被后挡板刮下 → 落到台面 → 被推进金币堆，互相挤压、叠放 → 前沿的金币掉落并计分。
- **摩擦**：金币 0.42 → 0.6，台面 0.32 → 0.2。金币之间的摩擦大于金币与台面，整堆被推着往前走，而不是互相叠上去。
- **「轻松掉落」卡**：向前重力 3.2 → 1.2。原来的值超过静摩擦，选到这张卡时整台金币会全部滑落。
- **斜坡**：改为实心楔形块，背面贴住后挡板，底面贴着推板顶面（与挡板一样只留 0.01 的缝），顶面外侧高、内侧低，凸包碰撞体。边缘落下的金币落在斜面上，滑到推板顶面。
- **金币大小**：直径 +30%（内容宽度的 6% → 7.8%），厚度不变；2D 下落金币改为与 3D 相同的古铜金。老虎机符号碰撞半径相应缩小，保证金币仍能从钉子和符号之间通过。
- **稳定性**：金币开启连续碰撞检测（薄币高速下落不穿过推板和斜坡）。
- **调试**：
  - `-autoplay`：每 0.4 秒投一枚，自动选卡；
  - `-autoplay` 或 `-debugPhysicsLog`：每秒打印推板上 / 台面上 / 已掉落 / 被拒的金币数和帧率。
- **测试**：新增在真实窗口里运行 SceneKit 物理的测试：推板推动金币堆、前沿掉币、没有丢弃；边缘金币沿斜坡滑下。另有「轻松掉落」不使整堆滑落。共 125 个用例全部通过。

5. **BOSS 数值**（`BossPlan`，只改 `GameConstants.bossPlan` 一行）：
   - 模型：每枚穿过场地的金币平均带出 e 枚奖励金币，奖励金币又是金币，所以返还率 r = 接币槽份额 × (1 + 只有玩家投币才有的) / (1 − e)。
     接币槽 0.92；e（不算 BOSS）= 金币卡 0.020 + 免费转动卡 0.006 + 老虎机 0.013 + 终极大奖起始值 0.010 = 0.049；只有玩家投币才有的 = 奖池 0.005 + 特殊金币 0.0025。各项来自 v11.8 的实测，这次没有重新长跑。

   - 按参考节奏（0.6 秒一枚）约 6 分钟 K.O. 一次，按住连投约 3 分钟。
   - K.O. 判定加了 0.0001 的余量（和勇士重击一样），一次掉血很小时不会剩一丝血。
