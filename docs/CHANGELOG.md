# CoinBounce 变更记录（代码/文档版本对齐）

> 规则：
> - 每次“可验收”的改动都必须：
>   - 更新 `PROJECT_VERSION.json` 的 `version`
>   - 更新相关产品/视觉规范文档中的版本表
>   - 更新/新增自动化测试用例
>   - 通过 `build_ios.sh`（以及后续的完整验收脚本）
> - 代码 tag 使用 `v<version>`，文档中也使用同一版本号。

## v9.5.0 (2026-04-20)

- **基线**：引入 `PROJECT_VERSION.json`、`.gitignore`、`docs/CHANGELOG.md`，用于后续迭代的版本/回滚管理。

## v9.5.1 (2026-04-20)

- **验收流水线**：新增 `tools/acceptance/` 自动化验收（跑单测→启动模拟器→截图→按区域对照参考图生成 Web 报告）。

## v9.5.2 (2026-04-20)

- **对齐迭代（进行中）**：推币台区域改用资源图 `coin_pusher_ref` 作为底图；投币按钮改为六边形并居中，新增箭头引导（由 `showTutorialArrow` 控制）。

## v9.6.0 (2026-10-26)

- **代码清理**：删除未使用的 3D/2.5D/测试场景和空壳文件；在用的老虎机视图拆到 `UI/SlotMachineView.swift`；测试 target 显式依赖 App target。
- **核心玩法闭环**：
  - SPIN 按钮改为调用 `spinSlot()`，修复点一次后永久卡在 spinning 的问题。
  - 金币落在 BONUS 滑块上会触发老虎机（转动中忽略）。
  - 顶部显示金币余额。
  - 新增 7 水果全亮二选一（+100 金币 / 点亮 2 个水果，选完重置水果）、奖励弹窗、JACKPOT 全屏庆祝。
  - 本地存档：金币、累计赢币、水果进度、是否投过币（UserDefaults）。首次安装 1000 金币。金币为 0 时投币按钮置灰并提示，预留 `requestFreeCoins()` 激励广告入口。
- **物理**：按 CADisplayLink 实际帧间隔步进，单步上限 1/30s；修复 display link 被创建两次导致物理每帧走两步的问题（整体速度相应变为原来的一半，需要重新评估手感）。
- **配置**：返奖数值集中到 `GameConstants`（数值不变）。
- **工程**：仅支持 iPhone（`TARGETED_DEVICE_FAMILY = 1`）。
- **测试**：新增老虎机回到 idle、BONUS 触发、存档往返、0 金币不可投币、帧步长上限、卡牌奖励等用例，共 39 个用例全部通过。


## v9.7.0 (2026-10-26)

- **统一布局**：新增 `GameLayout`，只根据屏幕尺寸和安全区计算各区域 frame 和全部物理关键位置（格挡、水果中心、水果格挡、COIN/BONUS 滑块、进入推币台和掉落的分界线、推板前沿与行程）。物理坐标改为屏幕坐标（点），删除 `GameState` 里写死的坐标和 Canvas 的二次映射。
- **布局修复**：老虎机转轴裁切在外框内、彩灯沿边框排列；SPIN 移到转轴右侧；右侧不再被推币台底图撑宽裁切；BONUS 滑块单独一条轨道，可见且与命中判定一致；推板动画跟随物理推板。
- **金币绘制**：修复 Canvas 不刷新导致下落金币和推币台金币不显示（v9.6 已存在）。
- **速度**：新增 `GameConstants.simulationSpeed = 2.0`，按 ≤1/60s 子步推进，与 v9.5.2 一致；1/30s 帧上限保留。重力和下落速度按布局比例换算，各尺寸屏幕下落时长一致。
- **测试**：新增 SE / 16·17 / Pro Max 三种尺寸的布局测试和物理与布局一致性测试，共 54 个用例全部通过。
- **调试**：DEBUG 构建支持启动参数 `-debugAutoDrop N`（自动投 N 枚币，用于截图）。

## v9.8.0 (2026-10-26)

- **开局预铺金币**：每次启动在推币台上按六边形密排预铺一层金币，最前排贴近掉落线，最后一排贴着推板最远处。参数在 `GameConstants`（`prefillMaxRows`、`prefillEdgeGap`、`prefillBackGap`、`prefillRowLooseness`）。推板空转时不掉落；在 SE / 16e / 16·17 / Pro Max 尺寸下投 4～5 枚币就会推落第一枚。屏幕尺寸变化时，如果推币台还没落上新金币，会按新布局重新预铺。
- **推币台物理**：推板以金币边缘接触（原来以金币中心判断）；金币重叠按位置分离，迭代 `bedSolverPasses` 次，推力能沿着金币堆传到前排，不再只是叠到彼此上面。
- **推币台底图**：删除参考截图 `coin_pusher_ref`（含版权风险），改为代码绘制的简化推币台：后挡板、左右侧栏（带灯）、引导斜坡、绿色台面、推板、前沿掉落口，不画任何金币。同时删除了喷币管装饰。
- **测试**：新增预铺测试（不越界、不重叠，空转掉落不超过 2 枚，投 5 枚至少推落 1 枚，掉落按 `bedDropReward` 计分，换布局后重新预铺），共 59 个用例全部通过。
