# v12 素材清单（要 hj 用 ChatGPT 生成的图）

写于 2026-11-11。必须的 5 张，可选的 4 张。动画用代码做（位移、缩放、淡入淡出、爱心和金币），所以每个角色只要很少的几张定格图。

## 通用要求（每张都一样）

- **透明背景 PNG**，画面里只有角色：不要文字、不要地面阴影、不要边框、不要背景。
- **全身入画**，四周留 5% 左右的空白，头顶和脚都不能被裁掉。
- **画风**：和现有兔女郎一致。生成时把 `BunnyIdle.png` 作为参考图传上去（在仓库 `ios/CoinBounce/Assets.xcassets/BunnyIdle.imageset/`），提示词里写「和参考图同一画风」。
- **国王、王后用 Q 版（二头身到三头身）**：战斗区只有屏幕高度的 9.5%，角色显示出来约 70–90 pt 高，写实比例会看不清脸。粗一点的深色描边，颜色饱和。
- **同一个角色先生成一张，再把它当参考图生成其他姿势**，这样脸、衣服、配色不会变。
- 朝向：国王在左边，**面朝右**；王后在右边（BOSS 后面），**面朝左**。
- 生成后放到 `~/Downloads/CoinBounce_资料归档/v12_素材/`，文件名照下表。尺寸不用精确，我会裁切和缩放；不小于表里的数字就行。

## K.O. 动画怎么用这几张图（约 7 秒）

1. 0–1 秒：BOSS 倒下淡出；国王弹跳（有第 6 张就换成它）。
2. 1–2.5 秒：王后从哭（3）淡入到开心（4），向左滑到国王身边。
3. 2.5–6 秒：画面中间放大显示亲吻图（5），代码加爱心飘起、「K.O.! +50」，同时 50 枚金币开始从顶部落下。
4. 6–7 秒：大图淡出，BOSS 满血复活，王后回到 BOSS 后面变回哭的（3）。
