**结论：** 这一类游戏好玩，靠的是三件事。一是每个游戏有一眼能认出来的主题；二是有一个「大的东西」在等着（奖池、任务、特殊玩法），而且随时看得见离它多远；三是中奖时的演出舍得做。我们现在三样都弱：主题只有推币机有，奖池只有推币机有，演出只有文字横幅。

## 3. 轮盘重做

- 竖屏。下注桌竖着摆：号码 3 列 12 行，格子大，手指压格线和格角压得准；0 在最上面，外围注在两侧和下面。
- 支持全部内围注：直注 35:1、分注 17:1、街注 11:1、角注 8:1、线注 5:1，加原有的外围注。返还率仍是 36/37。
- **按住滑动**：手指按下后在桌面上滑，停在哪里就预览哪一注（被覆盖的号码变亮，浮出注型和赔率），松手下注。点一下也可以。
- 开转时一只**正面朝上的大转盘**弹出来（宽度接近屏幕宽），不再斜着放；木纹、金属高光、球道、隔片、转塔都重画；开出的号码显示在转盘中心，然后转盘收起、桌上中奖的注亮起来。
- 重复下注、加倍、撤销、清空。

## 4. 老虎机重做：「财神到」

- 5 列 3 行、10 条线保留；图案换成中国风（元宝、红包、铜钱、福字、灯笼、鞭炮，10/J/Q/K/A 做低分）。
- **顶部四档奖池** MINI / MINOR / MAJOR / GRAND，数字一直在跳；GRAND 是累积的（每次下注抽一小部分进去），其余三档固定倍数。
- **锁定重转**（已有的数学）：6 枚以上金币触发，金币上是倍数或 MINI / MINOR / MAJOR；15 格全满得 GRAND。
- **天降财神**：随机触发，财神从上面降下来撒金币，把若干格变成百搭再结算。
- 免费转保留。中奖演出分三档（大奖、巨奖、超级大奖），金额滚动上涨、金币雨。
- 返还率仍然精确计算，目标 0.95 左右。
